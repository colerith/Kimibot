# 惊喜抽奖

用户入口：小蛋报到 → 身份抽奖 → 普通抽奖 / 惊喜抽奖。
普通抽奖保留试试手气、五连、十连及原有保底规则。

管理入口：`/社区面板 管理` → 身份管理 → 奖池/图鉴 → 惊喜抽奖配置。

1. 通过“待添加身份组”列表添加身份组，按服务器层级从上到下排列，每页 25 项，可独立翻页或搜索名称 / ID；“已配置”使用另一套翻页。设置中奖分配权重及显示 Emoji。留空 Emoji 时使用身份组原有 Unicode Emoji 或上传图标。Emoji 可留空保存；缺少原图标时，开放抽奖前再补充 Emoji。待添加列表可多选后统一设置权重；已配置列表多选后点击“编辑所选 / 批量权重”，每批最多 25 个，保留各自 Emoji。
2. 配置总中奖率、单抽费用与重复奖励。初始费用沿用配置时的普通单抽费用，总中奖率默认 10%，重复奖励默认 1 碎片。费用之后可独立修改。
3. 图标必须可区分，非必中模式至少需要两个有效身份组；权重为 0 时暂停该身份组。确认后点击“开放惊喜抽奖”。首次默认暂停且为空奖池。

普通与惊喜奖池互斥：已在普通奖池的身份组不会出现在惊喜待添加列表，已在惊喜奖池的身份组也不会出现在普通待添加列表（暂停配置仍占用）。如需迁移，先从原奖池移除再添加到另一边；保存时会再次检查。

中奖率表示三个位置完全一致的总概率，中奖后再按身份组权重分配。例如总中奖率 10%，两个身份组权重 1:3，则单次概率分别为 2.5% 和 7.5%。未中奖时三个位置不会完全一致，三个位置不是独立随机抽取。

新身份组进入永久衣柜并尝试自动穿戴；已有藏品、兑换归属或当前穿戴的身份组视为重复，转换为碎片。惊喜抽奖不计入普通抽奖保底。可查询奖池、碎片和上次结果；碎片暂不提供兑换。

费用、结果、碎片和归属在蛋壳 SQLite 数据库的同一事务中保存，独立 `surprise_state` 表不受旧蛋壳快照保存影响。交互 ID 用于防止重复结算，衣柜镜像可在重新打开惊喜抽奖或重启时恢复。显示或自动穿戴失败不会再次扣款。备份时需同时备份蛋壳数据库及身份组状态数据库。

代码更新后需重启机器人并重新打开用户/管理员面板。旧的已打开普通抽奖面板仍按原流程工作。
