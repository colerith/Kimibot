# 定期邀请面板

默认频道：1563535291850170389。加载 weekly_invite 扩展后，Bot ready 时启动后台检查（每 30 秒）。北京时间周一 00:00 至周六 00:00 开放；周末显示暂未开放。邀请不限使用次数，使用 Discord 原生有效期，Bot 离线不会延长有效期。重启后在开放时段补建，截止时间仍为本周六。

入口：`/社区面板 管理` → 定期邀请面板，仅管理员 / 服主可操作。

- 发送 / 恢复：启用自动发布并刷新面板，仍遵守暂停区间与周末限制。
- 撤销面板与链接：立即撤销有效邀请、删除面板并关闭自动发布；失败由后台重试。
- 编辑文案：修改标题、说明，保留当前管理页面。
- 设置停止创建区间：每行 `YYYY-MM-DD ~ YYYY-MM-DD`，包含起止日期；填写“清空”移除。已有链接仍到本周六失效，若需立即关闭请撤销。
- 寒暑假日期未预设，需要管理员按实际日期填写。结束暂停后如果仍在本周开放时段，会补建。

频道需允许 Bot 查看、发送消息、嵌入链接、读取历史消息、创建邀请；还需管理频道权限，以恢复结果不确定的邀请创建请求、撤销邀请。无需管理员权限。请求串行限速，遇到 429 退避。状态保存在共享 SQLite 的 weekly_invite 命名空间，跨重启保留；不要删除状态来强制刷新。

默认说明写明本周截止时间和有效期内检查网络，并包含传播范围与寒暑假暂停说明。后台在创建、发送前记录尝试，响应丢失后先查询恢复；查询失败会停止新建，避免重复。

部署：更新代码并重启 PM2 的 kimi 进程，检查扩展成功加载；进入管理入口发送 / 恢复，验证指定频道、按钮、链接截止时间。周末仅有关闭状态面板属正常。实际权限与 Discord API 仍需部署后验证。
