# 小蛋晋升

默认申请入口频道：`1559382179677470800`。申请展示卡片及置底审批导航子区：`1563529208943083540`。审批结果日志频道：`1419652525249794128`。权益身份组：`1417722389718110249`（破壳而出）。

机器人启动并准备就绪后自动部署入口及置底审批导航。通过 `/社区面板 管理` → 其他面板维护 → 小蛋晋升面板进入晋升管理台，无需新增 slash 命令同步。

管理台支持编辑标题、欢迎说明、权益说明、申请条件、申请须知，并可预览和手动刷新入口与置底导航。文案编辑只改变展示内容，不改变权益数值或表单校验规则。统计按今日 / 累计正式申请、管理员测试记录分别展示待审、发放中、通过、驳回与私信异常；今日按申请提交批次统计。编辑后保留当前管理台，可返回上一级社区管理。

申请入口频道、申请记录与导航频道 / 子区、审批结果日志频道可分别修改，保存前校验当前服务器、频道类型及机器人权限。修改相应位置后停用旧入口或清理旧导航，在新位置部署；历史申请保留原频道，继续审批且链接不变。新日志使用新日志频道，已发送或发送中日志保留原频道用于更新及中断恢复。子区需发送子区消息及上传附件权限，已归档但未锁定时自动取消归档；已锁定时等待管理员处理。配置持久化在独立 `promotion_settings` 表，旧版申请仍归属于原频道；升级后新申请默认进入指定子区，并清理原入口频道的旧导航。

公开面板不再显示名额行中的“测试记录不占名额”及“管理员 / 服主自动享有权益；其申请标记为测试记录，不占名额。”整行，旧版保存的相同文案也会从展示中移除；权限与名额规则不变。

成员上传 2–6 张图片（每张最多 8 MB）及至少 30 个非空白字符的感想。面板说明使用日月西 / 象牙塔超过 100 楼，需首楼、末楼、楼层数及相关痕迹；可打码具体内容。材料公开展示，截图内容及真实性由服主人工核验。

申请展示与安利投稿一致：图片使用 Discord 原生附件展示，下方为申请信息 Embed 和审批按钮。审批更新显式保留原附件。旧 Components V2 卡片无法直接切回 Embed，后台会从本地 `data/promotion_uploads/` 或原消息附件恢复全部图片后补发标准记录，更新导航，并在旧消息留下跳转；不会再次扣名额或发奖。缺失原图时保留原记录并在日志说明缺失文件，等待恢复后重试，避免发送无图替代记录。

每天北京时间 0 点开启新批次，最多接收 100 份有效申请。名额在数据库事务中保留，驳回也不退回当日名额；驳回后可重新申请。一个成员同时只能有一份待审 / 发放中申请，已有权益者不重复申请。申请编号永久递增。

申请卡片有通过 / 驳回按钮，仅服务器服主可操作；驳回弹窗必须填写理由。结果更新原卡片，写入指定记录频道，并私信成员。审批记录含私信送达状态；关闭私信显示未送达，不影响权益。网络故障会自动重试；进程在私信发送中断时保留待确认状态，避免反复私信。日志或卡片发送后进程中断，会先查历史恢复消息 ID。

## 永久权益

- 首次开通 100 蛋壳，只发一次；开通当天另有 30 蛋壳。
- 每个北京时间自然日自动到账 30 蛋壳，无需签到。停机期间从上次到账日补齐；开通前不追溯历史。
- 普通和惊喜身份组抽奖八折，商城身份组在当前有效售价上八折。月卡购买、转账等其他消费不打折。沿用一位小数蛋壳精度，四舍五入；惊喜连抽按每抽实际价格求和。
- 永久权益独立于普通月卡，普通月卡每日奖励照常。开通后不设到期时间，重复授予身份组不重复赠送首次奖励。
- 启动时完整加载成员并为所有已有身份组的非机器人成员开通权益；运行中手动授予身份组也会自动开通。批量开通只操作本地账本，不向每位旧成员群发私信。

审批先持久化服主决定，再授予身份组，最后在同一个 SQLite 事务内开通权益与标记通过。授予失败停留在发放中，后台恢复；重复按钮、重启和后台重试不重复赠礼。

## 限速与运行

晋升 REST 请求共用串行队列，每次请求结束后至少间隔 1 秒，并复用全局请求调度和 Pycord 路由限速；遇到外层 429 按 Retry-After 延后，至少冷却 30 秒。置底导航每 30 秒检查，只有频道末尾或内容变化时才更新，先发送新导航再清理旧导航。成员名额判断不依赖面板刷新时间。

机器人需要两个频道的查看 / 发送 / 嵌入链接 / 读取历史权限，申请频道还需附件权限。机器人最高身份组须高于破壳而出，并具有管理身份组权限；成员 Intent 已在主程序开启。

所有申请、权益和补发凭据在蛋壳数据库 `data/user_points.sqlite3` 的独立 `promotion_*` 表，不受旧版蛋壳快照重写影响。待投递截图保存在 `data/promotion_uploads/`（已加入 Git 忽略）；部署时保留数据库及该目录，备份时一同保存。

本地测试不代表服务器已上线。更新代码并重启机器人后，检查模块加载日志、两个频道的面板、服主审批及实际到账。

## 管理员与服主

服主及拥有 Discord「管理员」权限的非机器人成员自动开通同一套永久权益，不要求先持有破壳而出身份组。启动 / 重连扫描成员，以及权限、身份组、服主变更后自动补齐，首次赠礼仍只发一次。

管理员 / 服主提交时按服务端权限标记为测试记录，已享有权益也可以申请；即使每日普通申请已满，也可提交。测试记录不计入每日 100 个名额，展示卡片、审批记录及私信均标记测试；通过测试只改变审批状态，不授予身份组、不额外赠送蛋壳。仍只允许一份正在处理的申请，处理完可再次测试，审批权限仍仅限服主。普通成员的历史申请默认按正式记录计数。
