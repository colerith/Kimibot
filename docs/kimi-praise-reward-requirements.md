# 赞美奇米蛋奖励需求文档

## 1. 功能目标

在指定频道内，用户发送固定文本后，可以每日领取一次随机蛋壳奖励。

## 2. 触发规则

- 监听频道：`1450480250210484357`
- 触发文本：`赞美奇米蛋！`
- 文本需要完全匹配，前后空白会被忽略。
- 每个用户每天只有 1 次成功领取机会。

## 3. 奖励规则

- 成功触发后随机奖励 `1 - 9` 蛋壳。
- 奖励越高越稀有。
- 默认权重为 `[90, 70, 52, 36, 24, 15, 9, 4, 1]`，分别对应 `1 - 9` 蛋壳。
- 奖励写入蛋壳流水，来源为 `kimi_praise`。

## 4. 反馈规则

- 验证通过并发放奖励后，Bot 给该消息添加对应数字反应：
  - `1` 蛋壳：`1️⃣`
  - `2` 蛋壳：`2️⃣`
  - `3` 蛋壳：`3️⃣`
  - `4` 蛋壳：`4️⃣`
  - `5` 蛋壳：`5️⃣`
  - `6` 蛋壳：`6️⃣`
  - `7` 蛋壳：`7️⃣`
  - `8` 蛋壳：`8️⃣`
  - `9` 蛋壳：`9️⃣`

重复领取不加反应、不重复发奖。
